# Pix & Matcha — site vitrine

Site statique (aucun code d'application ici) hébergé sur GitHub Pages.

| Page | Contenu |
|---|---|
| `/` | Accueil du studio et catalogue des jeux |
| `/artclue/` | Landing page d'ArtClue : Enquête & Histoire de l'Art |
| `/artclue/privacy.html` | Règles de confidentialité d'ArtClue (URL déclarée dans la Play Console) |

Ajouter un jeu : créer un dossier `/<nom-du-jeu>/` avec son `index.html` et son `privacy.html`, puis ajouter sa carte dans `index.html`.

Aucun service tiers n'est chargé (polices embarquées, pas d'analytics) : pas de bandeau cookies nécessaire.
